# Flashcards

| Front | Back |
|-------|------|
| Inertial mass \(m_i\) | Resistance to acceleration in \(F=m_i a\) |
| Gravitational mass \(m_g\) | Coupling charge in Newtonian gravity |
| Universal free fall (Newton+equality) | \(a=GM/r^2\) independent of test mass |
| Equivalence (local) | Free fall removes gravity locally; tides limit global claim |
| Geodesic (pedagogical) | Straightest path in the geometry; free fall |
| Einstein equation (words) | Geometry \(G_{\mu\nu}\) related to stress-energy \(T_{\mu\nu}\) |
| Schwarzschild radius | \(r_s=2GM/c^2\) |
| Event horizon | Causal boundary, not material surface |
| Static redshift factor | \(\sqrt{1-r_s/r}\) for static observers \(r>r_s\) |
| Horizon vs singularity | Distinct concepts |
| EHT ring | Lensed emission/shadow structure — not solid horizon photo |
| Weak-field light deflection | \(\alpha\approx 4GM/(bc^2)\) |
