# Answer Key (Reasoning)

## Lesson 1

1. **Larger force but same \(a\):** When \(m_i=m_g\), both force and inertia scale with test mass, so \(a=GM/r^2\).  
2. **Which mass:** \(F=ma\) uses inertial mass; Newton gravity uses gravitational mass.  
3. **Not a proof of curved spacetime:** equality is a clue motivating equivalence / geometric gravity.  

## Lesson 2

1. Free-fall scale reads ~0 locally.  
2. Enlarged elevator reveals tides — equivalence is local.  
3. Standing on Earth: ground provides proper acceleration.  

## Lesson 3

1. Map geometry ≠ globe geometry.  
2. Free fall = geodesic / natural motion in the geometric view.  
3. Rubber sheet misleads if taken as literal external-down embedding of spacetime.  

## Lesson 4

1. \(T_{\mu\nu}\) includes energy, momentum, pressure, stress.  
2. \(G_{\mu\nu}\) is geometry side.  
3. Course goal: interpret, not fully derive/solve.  

## Lesson 5

1. Newtonian \(v_{\mathrm{esc}}=c\) is a scale clue.  
2. Horizon = causal boundary.  
3. Horizon ≠ singularity.  

## Lesson 6

1. Static formulas are not free-fall horizon formulas.  
2. Larger BH → weaker horizon tides.  
3. Permanent bright freeze-frame is misleading.  

## Lesson 7

1. Orbits constrain mass/compactness scale.  
2. EHT: emission/shadow/photon-region structure — not a solid shell photo.  
3. Multiple channels reduce method-specific error.
