# Misconception Clinic

Interactive copy: `practice/index.html` and inline lesson callouts.

| Misleading claim | Correction |
|------------------|------------|
| Gravity pulls equally hard on all objects | Force scales with \(m_g\); acceleration matches when \(m_i=m_g\) |
| Masses equal by definition | Different roles; equality is empirical |
| Standing on Earth is inertial | Weight means proper acceleration; free fall is inertial |
| Rubber sheet is literal spacetime | Embedding analogy; can smuggle external “down” |
| Curved graph line = curved spacetime | Coordinates can bend geodesic appearance |
| Only rest mass sources curvature | Pressure/stress/energy/momentum in \(T_{\mu\nu}\) |
| Newtonian escape proves GR holes | Clue for scale only |
| Horizon is a material surface | Causal boundary |
| Local time stops for the infaller | Finite proper time to horizon |
| Bright frozen infaller forever | Signals redshift and fade |
| Infaller sees entire future | Unsafe popular slogan |
| Horizon = singularity | Distinct |
| Bigger holes have stronger horizon tides | Opposite trend at \(r\sim r_s\) |
| EHT photographed the horizon shell | Emission/shadow/photon-region imaging |
| Einstein just hated dice | Completeness/locality/separability issues; accepted empirical QM success |
